# Sector Three Sim Lab — Website Concept

Website mockup for a fictional performance sim racing lab in Mooresville, NC. Styled like a live race timing screen: purple, green and yellow only ever mean fastest overall, personal best and slower than PB.

**Live:** https://thinkfirstjason.github.io/sector-three-sim/

- Single static `index.html`, no build step
- Design language for reuse: [DESIGN.md](DESIGN.md)
- Photos from [Unsplash](https://unsplash.com) (Unsplash License)

Fictional business. Names, addresses and phone numbers are made up.
